# LINE 社群科普貼文

這是互動交流群，群主是帶新手的角色。貼文要像群主在講解，不要像數據報表，也不要只是閒聊暖場。

## 格式（以使用者實際發出的「爆倉」那篇為準）

```
📚 週一幣圈小科普｜什麼是「爆倉」？

近期 BTC 大幅下跌，市場也出現大量槓桿部位遭到強制平倉的情況 💥

簡單來說，開 10 倍槓桿，價格反向走 1%，保證金就可能虧損 10%。如果虧損持續擴大，觸發強平條件，就會被交易所強制平倉。

更要注意的是「連環清算」：

多單爆倉 → 賣壓增加 → 價格繼續跌 → 更多人爆倉。

這也是為什麼行情有時候會突然加速下跌！
```

- 標題：`📚 週X幣圈小科普｜<一個問題>？`
- 第一段用 1–2 句帶到近期市場發生的事，說明為什麼今天講這個。
- 「簡單來說」：用具體數字解釋觀念。數字要算對（例：10 倍槓桿，價格反向 1%＝保證金虧 10%）。
- 「更要注意的是」：延伸一個大家容易忽略的重點，可以用 → 箭頭畫出因果鏈。
- 最後一句收尾，點出這個觀念的意義。不要用提問結尾。
- 全文大約 8–12 行，emoji 少量就好。

## 後續可以接的兩則（使用者會自己接，提供草稿時可以一併附上）

1. 引導看記事本：「都有整理一些必看文章在記事本，新來的夥伴們有空都可以看一下～」
2. 把科普接回風控觀念，用群主口吻：「這也是為什麼我一直提醒大家，風控跟倉位管理真的很重要！……希望大家能做好資金配置，不要一次把資金全部投入市場。」

記事本裡現有的文章：風險管理（新人必看）、BTC 現貨分批布局計畫。主題可以順著連到這兩篇。

## 選主題

- 從 `crypto_news.json`（或 `archive/`）這週的新聞裡，挑一個事件背後的觀念來講，例如爆倉、資金費率以外的清算機制、恐懼貪婪指數、穩定幣脫鉤、跨鏈橋被駭、ETF 是什麼。
- 優先選能接回風控、倉位管理、分批布局的主題。
- 週三不發，社群已經有籌碼快報，也不要寫籌碼類主題（ETF 資金流、多空比、資金費率）。

## 不要

- 數據報表式的貼文（一堆價格、漲跌幅、排行）。
- 純聊天暖場、沒有知識內容的貼文。
- 推薦特定幣種、喊單、保證報酬，或把冷門小幣的漲幅貼出來。
